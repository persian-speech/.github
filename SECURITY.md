# Security Policy · سیاست افشای امن آسیب‌پذیری

<div dir="rtl">

تیم نویسا امنیت داده‌ها، کلیدهای API و زیرساخت کاربران را با اولویت بالا بررسی می‌کند. لطفاً هیچ آسیب‌پذیری امنیتی، کلید API، توکن یا دادهٔ خصوصی را در Issueهای عمومی گیت‌هاب ثبت نکنید.

## گزارش امنیتی

- از طریق بخش **پشتیبانی** داخل پلتفرم [persianspeech.com](https://persianspeech.com) تیکت با موضوع **«گزارش امنیتی»** ثبت کنید، یا
- از قابلیت **Report a vulnerability** (GitHub Private Vulnerability Reporting) در مخزن مربوطه استفاده کنید.

لطفاً در گزارش خود موارد زیر را ذکر کنید:
1. مخزن یا مسیر سرویس، نسخه و محیط (وب، دسکتاپ یا سازمانی)
2. گام‌های بازتولید حداقلی بدون افشای داده‌های واقعی کاربران
3. اثر احتمالی و پیشنهاد اصلاح (در صورت وجود)

## Reporting a Vulnerability

Please **do not** report security vulnerabilities, API keys, tokens, or private user data in public GitHub issues.

- Open a support ticket titled **"Security Report"** inside [persianspeech.com](https://persianspeech.com), or
- Use GitHub's **Report a vulnerability** (Private Vulnerability Reporting) tab on the affected repository.

Include the affected component/version, minimal reproduction steps, and potential impact. We acknowledge reports promptly and coordinate disclosure after a fix is deployed.
