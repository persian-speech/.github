## Getting Help

- **Account, billing, private files, and enterprise licenses:** open a support ticket inside [persianspeech.com](https://persianspeech.com).
- **Developer API documentation and runnable examples:** open an issue in [persian-speech/nevisa-developers](https://github.com/persian-speech/nevisa-developers/issues) (never include API keys or private recordings).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md).
