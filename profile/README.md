## Build with Nevisa

Nevisa by ASR Gooyesh Pardaz provides Persian speech and text services for web, desktop and enterprise deployments.

- **Nevisa Live, File and Fusion** — live speech, audio/video transcription and optional model fusion.
- **Ariana Nova and Ariana Ava** — text to speech with selectable preset speakers.
- **Bina** — image and PDF OCR.
- **Nevisa language model** — chat and text processing through an OpenAI-compatible API.

Start with the **[bilingual developer guide and runnable examples](https://github.com/persian-speech/nevisa-developers)**. Create an [API key](https://persianspeech.com/dashboard/account/api-keys) and try requests in the [developer playground](https://persianspeech.com/dashboard/developers). Available services depend on the installation and account.

For documentation and sample-code issues, use the [developer repository](https://github.com/persian-speech/nevisa-developers/issues). For account support and private recordings, use support inside [the platform](https://persianspeech.com).
