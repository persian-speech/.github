# نویسا | تبدیل گفتار فارسی به متن

**[persianspeech.com](https://persianspeech.com)**:
گفتار فارسی را در وب، اپلیکیشن دسکتاپ، ربات‌های تلگرام و بله و از طریق API به متن تبدیل کنید.

## امکانات

- **نویسا لایو:** تبدیل هم‌زمان صدای میکروفون به متن، با موتور جدید.
- **نویسا فایل:** تبدیل دقیق فایل صوتی و ویدیویی، با زمان‌بندی و تشخیص گوینده.
- **ویرایشگر بازبینی:** ویرایش متن هم‌زمان با پخش صدا؛ خروجی Word، PDF، SRT، VTT و متن.
- **خروجی‌های هوشمند:** خلاصه، نکات کلیدی، اقدام‌ها و صورت‌جلسه از روی متن.
- **علائم نگارشی و تبدیل اعداد** به انتخاب کاربر.
- **کیف پول و بسته‌ها:** شارژ آنلاین، بسته‌های ساعتی، رزرو بسته، کد تخفیف، رسید پرداخت و دقایق رایگان روزانه.
- **پشتیبانی:** تیکت پشتیبانی و صندوق پیام.
- **توسعه‌دهندگان:** کلید API شخصی و مستندات API.

## تازه‌ها (آبان ۱۴۰۵)

- **سایت جدید persianspeech.com** روی پلتفرم جدید نویسا؛ همه‌ی حساب‌ها، موجودی‌ها و بسته‌های قبلی منتقل شدند.
- **اپلیکیشن دسکتاپ ۲.۲** (ویندوز و اوبونتو): سبک‌تر و سریع‌تر، تایپ مستقیم در هر برنامه، به‌روزرسانی خودکار.
- **مدل آفلاین نویسا لایو ۱.۵** برای دسکتاپ: بدون اینترنت کار می‌کند؛ اشتراک یک‌ماهه، سه‌ماهه و شش‌ماهه.
- **ربات‌های تلگرام و بله با مینی‌اپ:** ورود با همان حساب سایت و انتقال خودکار موجودی حساب قدیمی ربات.
- **ورود با گوگل، ایمیل یا موبایل.**
